# Meme Generator

An interactive meme generator built with React and Vite that allows users to select random meme templates and add custom top and bottom text.

## Features

- Generate random meme templates dynamically from the Imgflip API
- Upload and customize your own images
- Real-time text preview for both top and bottom text
- Download high-resolution generated memes directly as PNG
- Fully responsive design optimized for desktop and mobile devices

## How It Works

1. Enter text in the **Top Text** field.
2. Enter text in the **Bottom Text** field.
3. Click **Get a new meme image** to generate a different meme template.
4. The selected image and text are combined dynamically to create the meme.

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS3
- Imgflip API

## Getting Started

### Installation

```bash
npm install
```
